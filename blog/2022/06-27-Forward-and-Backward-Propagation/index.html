Forward Propagation

Take a look at the diagram of a neural network with two hidden layers. Each neuron or unit has its own state denoted with an(L)a_{n}^{(L)}an(L)​ where nnn and LLL indicate which neuron in which layer the state aaa belongs to. This state of a neuron is called activation. It is the output of weighted sum of its inputs plus a bias passed through an activation function. The most commonly used activation function is sigmoid σ\sigmaσ.The weighted sum plus bias is represented as zn(L)z_{n}^{(L)}zn(L)​.

an(L)=σ(zn(L))=σ(∑iwn,i(L−1)ai(L−1)+bn(L−1))a_{n}^{(L)} = \sigma(z_{n}^{(L)}) = \sigma(\sum\limits_{i}^{}w_{n,i}^{(L-1)}a_{i}^{(L-1)}+b_{n}^{(L-1)})an(L)​=σ(zn(L)​)=σ(i∑​wn,i(L−1)​ai(L−1)​+bn(L−1)​)

For instance, the activations of the two neurons in layer 1 are:

a0(1)=σ(w0,0(0)a0(0)+w0,1(0)a1(0)+b0(0))a_{0}^{(1)} = \sigma( w_{0,0}^{(0)} a_{0}^{(0)} + w_{0,1}^{(0)} a_{1}^{(0)} + b_{0}^{(0)} )a0(1)​=σ(w0,0(0)​a0(0)​+w0,1(0)​a1(0)​+b0(0)​) a1(1)=σ(w1,0(0)a0(0)+w1,1(0)a1(0)+b1(0))a_{1}^{(1)} = \sigma( w_{1,0}^{(0)} a_{0}^{(0)} + w_{1,1}^{(0)} a_{1}^{(0)} + b_{1}^{(0)} )a1(1)​=σ(w1,0(0)​a0(0)​+w1,1(0)​a1(0)​+b1(0)​)

These two activations above can also be calculated using matrix multiplication:

$$ \begin{bmatrix} a_{0}^{(1)}\ a_{1}^{(1)} \end{bmatrix} = \sigma \begin{pmatrix} \begin{bmatrix} w_{0,0}^{(0)} & w_{0,1}^{(0)}\ w_{1,0}^{(0)} & w_{1,1}^{(0)} \end{bmatrix} \begin{bmatrix} a_{0}^{(0)}\ a_{1}^{(0)} \end{bmatrix} + \begin{bmatrix} b_{0}^{(0)}\ b_{1}^{(0)} \end{bmatrix} \end{pmatrix} $$

Let's replace the vectors and the matrix with symbols.

a(L)=[a0(L)a1(L)⋮an(L)],W(L)=[w0,0(L)w0,1(L)⋯w0,n(L)w1,0(L)w1,1(L)⋯w1,n(L)⋮⋮⋱⋮wk,0(L)wk,1(L)⋯wk,n(L)],b(L)=[b0(L)b1(L)⋮bn(L)]a^{(L)} = \begin{bmatrix} a_{0}^{(L)}\\ a_{1}^{(L)}\\ \vdots\\ a_{n}^{(L)} \end{bmatrix}, W^{(L)} = \begin{bmatrix} w_{0,0}^{(L)} & w_{0,1}^{(L)} & \cdots & w_{0,n}^{(L)} \\ w_{1,0}^{(L)} & w_{1,1}^{(L)} & \cdots & w_{1,n}^{(L)} \\ \vdots & \vdots & \ddots & \vdots \\ w_{k,0}^{(L)} & w_{k,1}^{(L)} & \cdots & w_{k,n}^{(L)} \\ \end{bmatrix}, b^{(L)} = \begin{bmatrix} b_{0}^{(L)}\\ b_{1}^{(L)}\\ \vdots\\ b_{n}^{(L)} \end{bmatrix}a(L)=​a0(L)​a1(L)​⋮an(L)​​​,W(L)=​w0,0(L)​w1,0(L)​⋮wk,0(L)​​w0,1(L)​w1,1(L)​⋮wk,1(L)​​⋯⋯⋱⋯​w0,n(L)​w1,n(L)​⋮wk,n(L)​​​,b(L)=​b0(L)​b1(L)​⋮bn(L)​​​

Activations for all neurons in layer LLL are caculated as:

a(L)=σ(W(L−1)a(L−1)+b(L−1))a^{(L)} = \sigma(W^{(L-1)} a^{(L-1)} + b^{(L-1)})a(L)=σ(W(L−1)a(L−1)+b(L−1))

i.e. it is a linear transformation of weights with respect to its basis passed through an activation function.

Forward propagation is the calculation of each layer’s activations "propagating" input data forward to the output.

Implementing Forward Propagation

Before implementing the forward propagation, let's set activation and loss functions first. Sigmoid is used for activation, and mean squared error is used for calculating the loss.

σ=11+e−x\sigma = \frac{1}{1+e^{-x}}σ=1+e−x1​

mse=12∑(y^−y)2mse = \frac{1}{2}\sum(\hat y - y)^2mse=21​∑(y^​−y)2

We also need to prepare test input and initialize weights. I set[0.5, 0.35] as the input and [0.725] as the target value. Initial weights are chosen randomly from the standard normal distribution.

Using row-vectors

Vectors are commonly implemented as row-vector using an array. The activation vectors and weight matrices are transposed and calculated as:

(a′(L))=σ((a′(L−1)W′(L−1))+b′(L−1)(a'^{(L)})= \sigma((a'^{(L-1)}W'^{(L-1)}) + b'^{(L-1)}(a′(L))=σ((a′(L−1)W′(L−1))+b′(L−1) 
import numpy as np # linear algebra

Y = [[0.725]] # target value
X = np.array([[0.5, 0.35]]) # test data
W = [np.random.randn(2,2), np.random.randn(2,2), np.random.randn(2,1)] # initialize weights with standard normal distribution
B = [np.random.randn(1,2), np.random.randn(1,2), np.random.randn(1,1)]

sig = lambda x: 1/(1+np.exp(-x)) #sigmoid
mse = lambda x, y: 0.5*np.square(x-y).sum() # loss funcition

def forward_pass(X, W, B):
    for i,w in enumerate(W):
        X = sig(np.dot(X, w)+B[i]) # X*W
    return X

pred = forward_pass(X, W, B)
print("prediction:", pred, "loss:", mse(pred, Y))

Backpropagation

Backpropagation is an algorithm that trains the neural network by minimizing a cost function. It does so by adjusting each weight in proportion to the gradient of loss functions. Intuitively, the gradient of each weight represents how much it contributes to the overall error. The algorithm adjusts each weight in proportion to its contribution. Refer to 3Blue1Brown's video for better explanation.

Chain Rule

Given the cost of forward propagation with respect to weights in the last hidden layer as:

C(w(L−1))=C(a(L)(z(L)(w(L−1))))C(w^{(L-1)}) = C(a^{(L)}(z^{(L)}(w^{(L-1)})))C(w(L−1))=C(a(L)(z(L)(w(L−1)))) C=(y^−y)2,a(L)=σ(z(L)),z(L)=W(L−1)a(L−1)C = (\hat y - y)^2, \quad a^{(L)} = \sigma(z^{(L)}), \quad z^{(L)} = W^{(L-1)} a^{(L-1)}C=(y^​−y)2,a(L)=σ(z(L)),z(L)=W(L−1)a(L−1)

The gradients are calculated using the chain rule.

C′(w(L−1))=∂C∂a(L)⋅∂a(L)∂z(L)⋅∂z(L)∂w(L−1)C'(w^{(L-1)}) = \frac{\partial C}{\partial a^{(L)}} \cdot \frac{\partial a^{(L)}}{\partial z^{(L)}} \cdot \frac{\partial z^{(L)}}{\partial w^{(L-1)}}C′(w(L−1))=∂a(L)∂C​⋅∂z(L)∂a(L)​⋅∂w(L−1)∂z(L)​

Let's calculate the partial derivatives.

∂C∂a(L)=(y^−y),∂a(L)∂z(L)=σ′(z(L))=σ(z(L))⋅(1−σ(z(L))),∂z(L)w(L−1)=a(L−1)\frac{\partial C}{\partial a^{(L)}} = (\hat y - y), \quad \frac{\partial a^{(L)}}{\partial z^{(L)}} = \sigma'(z^{(L)}) = \sigma(z^{(L)}) \cdot (1-\sigma(z^{(L)})), \quad \frac{\partial z^{(L)}}{w^{(L-1)}} = a^{(L-1)}∂a(L)∂C​=(y^​−y),∂z(L)∂a(L)​=σ′(z(L))=σ(z(L))⋅(1−σ(z(L))),w(L−1)∂z(L)​=a(L−1)

Then,

C′(w(L−1))=(a(L−1))T⋅(y^−y)⊙σ′(z(L))C'(w^{(L-1)}) = (a^{(L-1)})^T \cdot (\hat y - y) \odot \sigma'(z^{(L)})C′(w(L−1))=(a(L−1))T⋅(y^​−y)⊙σ′(z(L))

a(L−1)a^{(L-1)}a(L−1) is transposed and multiplied to the left side to match the dimension.

The gradients with respect to weights in the second to last hidden layer are:

C′(w(L−2))=(a(L−2))T⋅(y^−y)⊙σ′(z(L))⋅(w(L−1))T⊙σ′(z(L−1))C'(w^{(L-2)}) = (a^{(L-2)})^T \cdot (\hat y - y) \odot \sigma'(z^{(L)}) \cdot (w^{(L-1)})^T \odot \sigma'(z^{(L-1)})C′(w(L−2))=(a(L−2))T⋅(y^​−y)⊙σ′(z(L))⋅(w(L−1))T⊙σ′(z(L−1))

And the gradients with respect to weights in the first layer are:

C′(w(0))=(X)T⋅(y^−y)⊙σ′(z(L))⋅(w(L−1))T⊙σ′(z(L−1)⋯(w(1))T⊙σ′(z(1))C'(w^{(0)}) = (X)^T \cdot (\hat y - y) \odot \sigma'(z^{(L)}) \cdot (w^{(L-1)})^T \odot \sigma'(z^{(L-1)} \cdots (w^{(1)})^T \odot \sigma'(z^{(1)})C′(w(0))=(X)T⋅(y^​−y)⊙σ′(z(L))⋅(w(L−1))T⊙σ′(z(L−1)⋯(w(1))T⊙σ′(z(1))

To calculate the gradients with respect to the bias, replace ∂z(n+1)∂w(n)\frac{\partial z^{(n+1)}}{\partial w^{(n)}}∂w(n)∂z(n+1)​ with ∂z(n+1)∂b(n)\frac{\partial z^{(n+1)}}{\partial b^{(n)}}∂b(n)∂z(n+1)​ which equals to 111:

C′(b(0))=[1,1,1,⋯ ]⋅(y^−y)⊙σ′(z(L))⋅(w(L−1))T⊙σ′(z(L−1)⋯(w(1))T⊙σ′(z(1))C'(b^{(0)}) = [1, 1, 1, \cdots] \cdot (\hat y - y) \odot \sigma'(z^{(L)}) \cdot (w^{(L-1)})^T \odot \sigma'(z^{(L-1)} \cdots (w^{(1)})^T \odot \sigma'(z^{(1)})C′(b(0))=[1,1,1,⋯]⋅(y^​−y)⊙σ′(z(L))⋅(w(L−1))T⊙σ′(z(L−1)⋯(w(1))T⊙σ′(z(1))

A 1×n1 \times n1×n matrix withh all ones is multiplied for the batch sum.

After the gradients have been calculated, update weights in proportion to the gradients.

wnew(L)=w(L)−(learning rate)∗C′(w(L))w_{new}^{(L)} = w^{(L)} - (\text{learning rate}) * C'(w^{(L)})wnew(L)​=w(L)−(learning rate)∗C′(w(L))

Implementing Backpropagation

Derivatives of sigmoid and mean squared error are:

σ′(x)=σ(x)⋅(1−σ(x))\sigma '(x) = \sigma(x) \cdot (1-\sigma(x))σ′(x)=σ(x)⋅(1−σ(x)) ∂∂y^mse=(y^−y)\frac{\partial}{\partial \hat y} mse = (\hat y - y)∂y^​∂​mse=(y^​−y) 
dsig = lambda A: A * (1-A) #derivative of sigmoid
dmse = lambda x, y: (x-y) #derivative of mse

For faster computation, let's modify the forward propagation function so that it stores a(L)a^{(L)}a(L) and σ′(z(L))\sigma'(z^{(L)})σ′(z(L)).

def forward_pass(X, W, B, A, dA):
    for i,w in enumerate(W):
        A.append(X)
        X = sig(np.dot(X, w)+B[i]) # X*W
        dA.append(dsig(X))
                  
    return X

# deep copy weights before updating them
new_W = []
new_B = []
for i, w in enumerate(W):
    new_W.append(w.copy())
    new_B.append(B[i].copy())

def backward_pass(X, W, B, A, dA, pred, Y, learning_rate=0.5):
    E = dmse(pred, Y) * dA[-1]
    for i, w in reversed(list(enumerate(W))):
        dw = np.dot(A[i].T, E)
        db = np.dot(np.ones(shape=(1, E.shape[0])), E)
        W[i] -= dw * learning_rate
        B[i] -= db * learning_rate
        if i>0:
            E = np.dot(E, w.T) * dA[i]

A, dA = [],[]
pred = forward_pass(X, new_W, B, A, dA)
for i in range(500):
    backward_pass(X, new_W, B, A, dA, pred, Y)
    pred = forward_pass(X, new_W, B, A, dA)
    if i %50 == 0:
        print("epoch:", i, "prediction:", pred, "loss:", mse(pred, Y))
